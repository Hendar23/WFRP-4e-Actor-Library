# Actor expansion: unfinished review draft

This branch is a checkpoint only. Do not install or release it.

It sketches 100 actors in total, including the working twelve: civilian tiers, criminals, soldiers, orc and goblin specialists, skaven slingers/runners, undead and six human spellcasters. Custom-rule specialists such as poison wind globadiers remain deferred.

The actor definitions and additional catalogue entries have been drafted. Runtime work on category folders, optional dependencies, selected ammunition, memorised spells and Ugly flaws has started. The build validator/schema still needs updating for the added fields. New actor mechanics and item compatibility have not been verified in Foundry.

The published main branch remains the working twelve-actor library. Review the existing actors first before proceeding with this expansion.
