## 0.3.2: Foundry installation and updates

- Adds a stable manifest URL for installation through Foundry Setup and subsequent Update checks.
- Packages the module as a release ZIP, with module.json at its root.
- Adds automated validation and release packaging on version updates to main.
- Documents and declares the Core Rulebook, Up in Arms and Warhammer Library dependencies.

Includes the same twelve pilot actor definitions and runtime as working version 0.3.1. Existing actor data is not rebuilt just for this packaging update. Expanded actor drafts, category-folder automation and Ugly flaws are deferred for review.

Requires Foundry 14, WFRP 10.0.0+, Warhammer Library 3.4.1+, Core Rulebook 8.0.0+ and Up in Arms 7.2.0+. Paid content must be owned and installed separately.
